# Task 2: Linux File Management

## Commands Practised

- mkdir: Creates directories.
- touch: Creates empty files.
- echo: Writes text into files.
- cat: Displays file contents.
- head: Displays the first lines of a file.
- tail: Displays the last lines of a file.
- wc -l: Counts lines in a file.
- cp: Copies files.
- mv: Moves and renames files.
- rm: Removes files.
- ls -R: Lists directories recursively.

## What I Learned

I learned how to create, copy, move, rename,
read and delete files using Linux commands.
I also practised organizing files into directories.
